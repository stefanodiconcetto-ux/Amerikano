# Amerikano

Versione web 1.9.36 del segnapunti Amerikano, preparata per GitHub Pages.

## Attivazione

In Settings → Pages scegliere Deploy from a branch, branch `main`, cartella `/ (root)`, quindi Save.

Indirizzo previsto dopo la pubblicazione: https://stefanodiconcetto-ux.github.io/Amerikano/

Android: menu del browser → Installa app. iPhone/iPad: Safari → Condividi → Aggiungi alla schermata Home.

Dopo il primo caricamento completo, l'app funziona offline; il cloud richiede rete. Per aggiornare, chiudere tutte le finestre dell'app e riaprirla. Non cancellare i dati del sito: partite, profili e accessi locali sono conservati nel browser. Il passaggio da APK o altri siti richiede un backup e il suo ripristino; i dati locali non si trasferiscono automaticamente.

Contiene soltanto asset web: nessuna chiave di firma Android, backup personale o credenziale privilegiata. La chiave Supabase pubblica ha ruolo anon. Nessun dato del cloud è incluso nella cache offline.

Origine: amerikano-segnapunti, commit 15752bce84c1bc42f462a07a7ee4153b8784d4aa. Verifica locale: 178 test app e 4 test Pages superati. Installazione su dispositivi e multiplayer sul dominio pubblicato non ancora verificati.
